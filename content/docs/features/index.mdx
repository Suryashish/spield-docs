Spield is one protocol with several products built on the same solvent core. Use the one that
matches what you want. Each maturity is its own [series](/docs/how-it-works/series-and-maturities),
and you choose it with the series selector in the app.

## Which product is right for me?

| If you want to... | Use... |
| --- | --- |
| Lock a guaranteed return, simplest possible | **Fixed-Rate Vault** |
| Hold the bond yourself, or trade it | **PT** (via Deposit or the market) |
| Take a leveraged view on yield | **YT** (buy YT on the market) |
| Earn fees from trading activity | **Liquidity** |
| Move USDC in or out from another chain | **Cross-chain bridge** |
| Hold a yield-bearing dollar with no maturity | **SR Wrapper** (see [SR](/docs/how-it-works/standardized-return)) |
| Check that the protocol covers what it owes | **Solvency dashboard** |

Each feature page explains what it does and how to use it. For the mechanics, see
[How It Works](/docs/how-it-works).

## Two yield sources

The features above work on **Blend USDC series**, which are live on mainnet and testnet.
A second family, **Treasury series** on Etherfuse USTRY, offers PT, YT, a market and liquidity
too, and is live on **mainnet** (since 27 November 2026) and testnet. See [Treasury series](/docs/how-it-works/treasury-series).
